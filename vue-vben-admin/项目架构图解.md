│ Route Access  │  │ Component Auth │  │ Button Auth  │

└───────────────┘  └────────────────┘  └──────────────┘
        │                   │                   │

                            │

### 权限检查流程

```
1. 用户登录
   login(credentials)
        │
        ▼
2. 获取权限
   fetchUserPermissions()
        │
        ├─→ permissions: ['user:read', 'user:edit']
        └─→ roles: ['admin']
        │
        ▼
3. 存储权限
   accessStore.setPermissions(permissions)
        │
        ▼
4. 权限检查
   hasAccess(['user:edit'])
        │
        ├─→ 路由守卫
        ├─→ 组件渲染
        └─→ 按钮显示
        │
        ▼
5. 动态路由
   generateRoutes(permissions)
        │
        ├─→ 过滤路由
        └─→ 添加路由
```

### 权限使用方式

```
1. 路由级别
   route: {
     meta: {
       authority: ['admin', 'user:edit']
     }
   }

2. 组件级别
   <AccessControl :codes="['user:edit']">
     <Button>编辑</Button>
   </AccessControl>

3. 指令级别
   <Button v-access="['user:edit']">编辑</Button>

4. 编程式
   const { hasAccessByCodes } = useAccess();
   if (hasAccessByCodes(['user:edit'])) {
     // ...
   }
```
