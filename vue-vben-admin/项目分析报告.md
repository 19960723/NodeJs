## 1. 项目概览

### 1.1 项目简介

**Vue Vben Admin** 是一个现代化的中后台管理系统模板，采用最新的前端技术栈构建。

- **🎨 多UI框架支持**: Ant Design Vue / Element Plus / Naive UI
- **🔧 Monorepo架构**: 基于 pnpm workspace + turbo
- **🚀 高性能**: Vite 构建，支持按需加载
- **💪 TypeScript**: 完整的类型支持
- **🎭 主题系统**: 支持多主题、深色模式
- **🌍 国际化**: 内置 i18n 支持

## 3. 项目架构

### 3.1 分层架构

```
┌─────────────────────────────────────┐
│        应用层 (apps/)               │
│  web-antd / web-ele / web-naive     │
│  - 路由配置                          │
│  - 页面视图                          │
│  - 适配器实现                        │
└───────────────┬─────────────────────┘
                │
┌───────────────▼─────────────────────┐
│      业务效果层 (effects/)          │
│  - 业务组件 (common-ui)              │
│  - 布局系统 (layouts)                │
│  - 权限控制 (access)                 │
│  - 网络请求 (request)                │
│  - 插件集成 (plugins)                │
└───────────────┬─────────────────────┘
                │
┌───────────────▼─────────────────────┐
│      核心层 (@core/)                │
│  - UI组件库 (ui-kit)                 │
│  - 基础工具 (base)                   │
│  - 组合函数 (composables)            │
│  - 类型定义 (typings)                │
└─────────────────────────────────────┘
```

**设计原则:**

1. **核心层** - 框架无关，可独立发布
2. **业务层** - 包含业务逻辑，但可跨应用复用
3. **应用层** - 具体业务实现

## 4. 核心设计理念

### 4.1 适配器模式 (Adapter Pattern)

为了支持多UI框架，项目使用**适配器模式**:

```typescript
// playground/src/adapter/component/index.ts
async function initComponentAdapter() {
  const components: Partial<Record<ComponentType, Component>> = {
    // Ant Design Vue 适配
    Input: withDefaultPlaceholder(AntInput, 'input'),
    Select: withDefaultPlaceholder(AntSelect, 'select'),
    DatePicker,

    // 自定义组件
    ApiSelect: withDefaultPlaceholder(ApiComponent, 'select', {
      component: Select,
      modelPropName: 'value',
      visibleEvent: 'onVisibleChange',
    }),
  };

  // 注册到全局
  globalShareState.setComponents(components);
}
```

**优势:**

- 统一的组件调用方式
- 轻松切换UI框架
- 业务代码与UI框架解耦

### 4.2 Schema驱动的表单系统

使用 **JSON Schema** 配置表单:

```typescript
import type { VbenFormSchema } from '@vben-core/form-ui';

const schema: VbenFormSchema[] = [
  {
    fieldName: 'username',
    label: '用户名',
    component: 'Input',
    componentProps: {
      placeholder: '请输入用户名',
    },
    rules: 'required',
  },
  {
    fieldName: 'age',
    label: '年龄',
    component: 'InputNumber',
    dependencies: {
      // 动态依赖
      triggerFields: ['username'],
      if(values) {
        return !!values.username;
      },
    },
  },
];
```

基于 **CSS变量** 实现动态主题:

import { computed } from 'vue';

import { Primitive } from 'radix-vue';

  as: 'div',
  bordered: true,

    'bg-card text-card-foreground rounded-lg shadow-sm',
    props.bordered && 'border border-border',
    props.class,

<template>

    <div v-if="title || $slots.header" class="border-border border-b px-6 py-4">

      </slot>
    </div>

    <div class="p-6">
      <slot></slot>
    </div>

    <div v-if="$slots.footer" class="border-border border-t px-6 py-4">
      <slot name="footer"></slot>
    </div>
  </Primitive>
</template>

### 5.3 开发业务组件

**示例: 创建一个用户选择器**

#### 步骤1: 创建组件

```bash
packages/effects/common-ui/src/components/user-selector/
├── user-selector.vue
├── types.ts
└── index.ts
```

#### 步骤2: 实现组件

```vue
<script setup lang="ts">
import type { UserSelectorProps } from './types';
import { ref, watch } from 'vue';
import { VbenSelect } from '@vben-core/shadcn-ui';
import { useRequest } from '@vben/hooks';
import { getUserListApi } from '@/api/user';

const props = defineProps<UserSelectorProps>();
const emit = defineEmits<{
  'update:modelValue': [value: string[]];
  change: [users: any[]];
}>();

const selectedUsers = ref<string[]>(props.modelValue || []);

// 使用业务API获取数据
const { data: users, loading } = useRequest(getUserListApi, {
  params: props.deptId ? { deptId: props.deptId } : undefined,
});

watch(selectedUsers, (value) => {
  emit('update:modelValue', value);
  const selected = users.value?.filter((u) => value.includes(u.id));
  emit('change', selected || []);
});
</script>

<template>
  <VbenSelect
    v-model="selectedUsers"
    :loading="loading"
    :options="users"
    :placeholder="placeholder || '请选择用户'"
    multiple
    filter-option
  >
    <template #option="{ item }">
      <div class="flex items-center gap-2">
        <img :src="item.avatar" class="h-6 w-6 rounded-full" />
        <span>{{ item.name }}</span>
      </div>
    </template>
  </VbenSelect>
</template>
```

### 5.5 开发可复用的Composable

**示例: 创建一个数据表格Hook**

```typescript
// packages/effects/hooks/src/use-table.ts
import { ref, computed } from 'vue';
import { useRequest } from '@vben/hooks';

export interface UseTableOptions<T> {
  api: (params: any) => Promise<{ list: T[]; total: number }>;
  defaultPageSize?: number;
}

export function useTable<T = any>(options: UseTableOptions<T>) {
  const { api, defaultPageSize = 10 } = options;

  const page = ref(1);
  const pageSize = ref(defaultPageSize);
  const searchParams = ref({});

  const {
    data,
    loading,
    run: fetchData,
  } = useRequest(api, {
    manual: true,
  });

  const dataSource = computed(() => data.value?.list || []);
  const total = computed(() => data.value?.total || 0);

  const handlePageChange = (newPage: number) => {
    page.value = newPage;
    fetchData({
      page: newPage,
      pageSize: pageSize.value,
      ...searchParams.value,
    });
  };

  const handleSearch = (params: any) => {
    searchParams.value = params;
    page.value = 1;
    fetchData({ page: 1, pageSize: pageSize.value, ...params });
  };

  return {
    dataSource,
    loading,
    total,
    page,
    pageSize,
    fetchData,
    handlePageChange,
    handleSearch,
  };
}
```

**使用示例:**

```vue
<script setup lang="ts">
import { useTable } from '@vben/hooks';
import { getUserListApi } from '@/api/user';

const {
  dataSource,
  loading,
  total,
  page,
  pageSize,
  handlePageChange,
  handleSearch,
} = useTable({
  api: getUserListApi,
  defaultPageSize: 20,
});

// 初始加载
onMounted(() => {
  handleSearch({});
});
</script>

<template>
  <div>
    <VbenTable
      :data-source="dataSource"
      :loading="loading"
      :pagination="{
        current: page,
        pageSize,
        total,
        onChange: handlePageChange,
      }"
    />
  </div>
</template>
```

## 7. 最佳实践

### 7.1 组件设计原则

#### ✅ DO - 应该做的

1. **单一职责**: 每个组件只做一件事
2. **Props设计**: 提供合理的默认值和类型定义
3. **事件命名**: 使用 `update:modelValue` 支持 v-model
4. **Slots灵活性**: 提供足够的插槽用于自定义
5. **样式可覆盖**: 使用 Tailwind 的 `cn()` 合并类名
6. **TypeScript**: 完整的类型定义

```vue
<script setup lang="ts">
// ✅ 良好的类型定义
interface Props {
  modelValue?: string;
  disabled?: boolean;
  placeholder?: string;
}

const props = withDefaults(defineProps<Props>(), {
  modelValue: '',
  disabled: false,
  placeholder: '请输入',
});

// ✅ 定义事件类型
const emit = defineEmits<{
  'update:modelValue': [value: string];
  change: [value: string];
}>();
</script>

<template>
  <!-- ✅ 支持插槽自定义 -->
  <div>
    <slot name="prefix" />
    <input :value="modelValue" @input="handleInput" />
    <slot name="suffix" />
  </div>
</template>
```

#### ❌ DON'T - 不应该做的

```vue
<script setup>
// ❌ 没有类型定义
const props = defineProps({
  value: String,  // 不推荐使用 value，应该用 modelValue
});

// ❌ 直接修改 props
const handleClick = () => {
  props.value = 'new value';  // 错误！
};

// ❌ 使用 any 类型
const data: any = ref();
</script>
```

## 8. 常见问题

### Q1: 如何在不同UI框架间切换?

**A:** 修改应用的适配器配置，重新注册组件映射。

### Q2: 如何扩展表单组件?

**A:**

1. 创建自定义组件
2. 在 `adapter/component/index.ts` 中注册
3. 在表单 schema 中使用组件名称

### Q3: 如何自定义主题?

**A:** 修改 `packages/@core/base/design/design-tokens/` 下的CSS变量。

### Q4: 如何处理权限?

**A:**

- 路由权限: 在路由 meta 中配置 `authority`
- 组件权限: 使用 `v-access` 指令或 `<AccessControl>` 组件
- 按钮权限: 使用 `v-access="'code'"` 指令

### Q5: 如何添加新的国际化语言?

**A:**

1. 在 `packages/locales/src/` 创建语言文件
2. 在应用的 `src/locales/` 添加对应翻译
3. 在 `bootstrap.ts` 中注册语言
