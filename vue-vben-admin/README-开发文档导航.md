## 🎯 学习路径推荐

### 第一阶段：了解架构（1-2 天）

1. **先看架构图** - [项目架构图解.md](./项目架构图解.md)
   - 快速浏览所有图解
   - 理解项目整体结构

2. **再看详细文档** - [项目代码分析报告.md](./项目代码分析报告.md)
   - 重点阅读：第 1-3 章（项目架构、Monorepo 结构、核心包）
   - 了解 `packages/@core` 和 `packages/effects` 的作用

### 第二阶段：学习开发规范（1 天）

1. **阅读规范章节** - [项目代码分析报告.md](./项目代码分析报告.md)
   - 第 4 章：组件开发规范
   - 了解命名、目录、代码规范

2. **查看示例代码** - 在项目中查看
   - `playground/src/views/examples/` - 组件示例
   - `packages/effects/common-ui/src/components/` - 业务组件源码
   - `packages/@core/ui-kit/` - 核心组件源码

### 第三阶段：实践开发（持续）

1. **跟随教程实践** - [项目代码分析报告.md](./项目代码分析报告.md)
   - 第 5 章：扩展组件开发指南
   - 从简单组件开始，逐步实践

2. **遇到问题查速查表** - [快速开发指南.md](./快速开发指南.md)
   - 表单怎么写？→ 查表单速查
   - 弹窗怎么用？→ 查弹窗速查
   - 样式怎么写？→ 查 TailwindCSS 速查

3. **参考最佳实践** - [项目代码分析报告.md](./项目代码分析报告.md)
   - 第 6 章：最佳实践
   - 性能优化、类型安全、状态管理等

## 💡 学习建议

### ✅ DO（推荐做法）

1. **先看图再看文字** - 架构图 → 详细文档
2. **边学边做** - 每学一个概念就实践一次
3. **参考示例代码** - playground/src/views/examples/
4. **遇到问题先查文档** - 善用搜索功能
5. **保留速查表** - 快速开发指南.md 随时查阅
6. **理解而非死记** - 理解设计思路比记住 API 更重要

### ❌ DON'T（不推荐）

1. **不要跳过架构学习** - 理解架构能事半功倍
2. **不要一次性读完所有文档** - 分阶段学习更高效
3. **不要只看不练** - 实践是最好的学习方式
4. **不要忽略示例代码** - 示例代码是最好的教材
5. **不要害怕阅读源码** - 源码是最准确的文档

## 🎯 目标检查清单

完成以下学习目标，你就可以熟练开发 Vben Admin 扩展组件了：

### 第一阶段：理解架构 ✓

- [ ] 了解 Monorepo 结构（apps / packages / internal）
- [ ] 理解包依赖关系（应用层 → 业务层 → 核心层）
- [ ] 知道 `@core` 和 `effects` 的区别和作用
- [ ] 了解 Shadcn UI、Form UI、Popup UI 的职责

### 第二阶段：掌握规范 ✓

- [ ] 了解组件命名规范（文件名、组件名、类型名）
- [ ] 了解组件目录结构规范
- [ ] 了解代码规范（import 顺序、props 定义、emit 定义）
- [ ] 了解样式规范（TailwindCSS、CSS 变量）

### 第三阶段：能开发组件 ✓✓✓

- [ ] 能创建简单组件（Vue 组件 + types.ts + index.ts）
- [ ] 能在表单中注册自定义组件（adapter）
- [ ] 能创建带 API 的高级组件（API 类 + Composable）
- [ ] 能使用 useVbenForm 创建复杂表单
- [ ] 能使用 useVbenModal/Drawer 创建弹窗
- [ ] 能创建自定义 Composable
- [ ] 能创建自定义指令

### 第四阶段：熟练开发 ✓✓✓✓

- [ ] 能独立开发完整的 CRUD 页面
- [ ] 能处理复杂的表单验证和联动
- [ ] 能进行性能优化
- [ ] 能处理权限控制
- [ ] 能自定义主题
- [ ] 能编写测试用例
