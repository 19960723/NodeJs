### 3.3 架构特点

#### ✅ 优点

1. **高内聚低耦合**: 每个模块职责清晰，依赖注入管理
2. **统一数据流**: 请求 → Guard → Controller → Service → Repository → DB
3. **横切关注点分离**: Interceptor、Filter、Guard 处理日志、异常、认证
4. **Repository 模式**: 数据访问层抽象，易于测试和替换
5. **DDD 思想**: 每个模块包含完整的 DTO、Entity、Repository

#### ⚠️ 可优化点

1. 缺少 Domain 层（领域模型）
2. 可以考虑引入 CQRS（命令查询职责分离）
3. 事件驱动机制尚未实现

```typescript
private async generateToken(user: User): Promise<LoginVo> {
  // Access Token: JWT (7天)
  const accessToken = this.jwtService.sign(payload);

  // Refresh Token: 随机字符串 (30天)
  const refreshToken = this.generateRefreshToken();

  // 存储到数据库（可撤销、可查询）

  return { accessToken, refreshToken, expiresIn, user };
}
```

### 6.1 统一返回格式

所有接口返回统一的 JSON 格式：

```typescript
{
  "code": 10000,              // 业务错误码
  "message": "操作成功",       // 提示信息
  "data": { ... },            // 返回数据
  "timestamp": "2024-11-21T10:00:00.000Z",  // 时间戳
  "requestId": "abc123"       // 请求追踪 ID
}
```

#### 实现方式

```typescript
@Injectable()
export class TransformInterceptor<T> implements NestInterceptor<T, Result<T>> {
  intercept(
    context: ExecutionContext,
    next: CallHandler,
  ): Observable<Result<T>> {
    return next.handle().pipe(map((data) => Result.success(data)));
  }
}
```

#### 特殊处理

**Prisma 错误映射**:

```typescript
switch (exception.code) {
  case 'P2002': // 唯一性约束
    message = '数据已存在，违反唯一性约束';
    errorCode = ErrorCode.ALREADY_EXISTS;
    break;
  case 'P2025': // 记录不存在
    message = '记录不存在';
    errorCode = ErrorCode.NOT_FOUND;
    break;
}
```

**环境区分**:

- **生产环境**: 只返回必要信息，隐藏敏感数据

## 9. 优势与亮点

### 9.1 技术亮点

#### 🌟 1. 双令牌机制

**问题**: 传统 JWT 无法撤销，长期有效不安全，短期频繁刷新体验差

**解决方案**:

```typescript
Access Token (7天, JWT)     ← 用于 API 调用
    ↓
Refresh Token (30天, 随机)  ← 存储数据库，可撤销
    ↓
撤销机制 (数据库黑名单)     ← 登出、异常登录时撤销
```

**优势**:

- ✅ 安全: 可撤销、可追踪
- ✅ 灵活: 支持单设备/多设备登录
- ✅ 体验: 自动续期，无感刷新

---

#### 🌟 2. 细粒度 RBAC

**问题**: 简单的角色权限无法满足复杂业务

**解决方案**:

```

    动态权限组合
```

**示例场景**:

```typescript

```

**优势**:

- ✅ 灵活: 权限可组合、可继承
- ✅ 可维护: 权限集中管理
- ✅ 可扩展: 新增资源只需添加权限

#### 🌟 3. Repository 模式

```typescript
// 基础 Repository
export abstract class BaseRepository {
  constructor(protected readonly prisma: PrismaClient) {}
}

// 用户 Repository
@Injectable()
export class UserRepository extends BaseRepository {
  async findByUsername(username: string) {
    return this.prisma.user.findUnique({ where: { username } });
  }

  // 事务支持
  async createWithRoles(userData, roleIds) {
    return this.transaction(async (tx) => {
      const user = await tx.user.create({ data: userData });
      await tx.userRole.createMany({ data: roleIds.map(...) });
      return user;
    });
  }
}
```
